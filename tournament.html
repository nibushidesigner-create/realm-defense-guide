Weekly Competition

Tournament Guide

Plan around the blessed hero, the weekly map, and clean wave timing instead of forcing the same campaign team every run.

Tournament Decision Notes

How to turn a weekly map into a score plan

Tournament runs are less about clearing once and more about repeating a clean rhythm. The best attempt usually comes after the player understands where the score run collapses: early leaks, cooldown desync, Boss drag, or a weak blessed hero plan.

Start with the blessed hero

If the blessed hero is strong on the map, build around them. If they are awkward, assign them a limited job such as lane holding, delay, or cleanup, then let two reliable heroes carry the scoring rhythm.

Map type changes the lineup

Long choke maps reward control chains and tower scaling. Open maps reward mobility and quick burst. Split maps punish greedy tower upgrades because a single unsupported lane can end a strong run early.

Record the failure wave

After every serious attempt, write down the wave number, leak type, and skill cooldown state. The next run should fix that exact failure instead of randomly changing the entire team.

Weekly Review Method

Build the run around evidence from the map

A tournament score plan should be written after two or three scouting attempts. The first run identifies enemy lanes and the blessed hero's realistic job. The second run tests whether tower upgrades or hero skills are ending the run. Later attempts should refine timing instead of changing the entire team every time.

Scouting attempt

Use the first ticket to map the dangerous wave, flyer timing, and whether enemies stack in a single choke or split into several routes. Do not chase a perfect score yet. The goal is to learn which lane deserves gold and which cooldown must be saved.

Refinement attempt

After the first failure, keep the same lineup if the roles are correct. Move the lane holder, delay the key control skill, or shift one upgrade into the wave that ended the run. Tournament improvement usually comes from cleaner rhythm, not constant roster changes.

Score-push attempt

Once the failure wave is stable, push score by tightening ability timing and reducing wasted movement. A strong final run keeps the blessed hero useful, protects the main tower zone, and saves emergency control for the wave that can still break the route.

Use the blessed hero when

  • The bonus lets them hold a lane, kill flyers, or survive the pressure wave.
  • The map has a role that matches their natural control or damage pattern.
  • Two support heroes can cover the parts of the map they cannot handle.

Limit the blessed hero when

  • Their range or movement wastes time on the weekly map.
  • The bonus does not solve the wave that actually ends the run.
  • They are useful only as cleanup while stronger heroes carry the route.

Stop changing teams when

  • The same wave fails because of one late skill.
  • Leaks happen after a tower upgrade is delayed too long.
  • The lineup reaches the target score window but loses consistency.
